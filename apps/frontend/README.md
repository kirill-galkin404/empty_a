# todo_frontend

Frontend for the Todo app. AngularJS 1.5 + Bootstrap 3, no build step.
Backend lives in [todo_backend](https://github.com/kirill-galkin404/todo_backend).

## Run

Start the backend first (http://localhost:3000), then:

```
npm install
npm start      # http://localhost:8080
```

API url is set in `js/config.js`.

Demo login (after `npm run seed` in backend): `demo` / `demo`.
